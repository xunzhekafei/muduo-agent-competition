# old_plan

这个目录用于存放历史计划、人员分工、阶段任务拆解、旧协作流程和早期业务策划材料。

这些文件保留作追溯参考，但不再放在主开发路径里，避免干扰当前接手、开发和联调。

## 目录说明

- `people/`: 按人员或个人负责范围整理的旧任务清单、模块报告。
- `product_plans/`: 旧的功能开发计划、阶段拆解、多人分工型产品文档。
- `collaboration/`: 旧协作手册、待办文档、商业策划等非代码运行所需资料。

## 使用建议

- 当前开发优先看根目录 `README.md`、`BUILD.md`、`docs/`、`contracts/` 和 `ai_space/PROJECT_HANDOFF_REPORT.md`。
- 需要追溯“某个模块当初为什么这么分工”时，再回到这里查历史计划。
- 新的 AI 过程性分析、梳理报告和临时交接材料请放到 `ai_space/`，不要继续堆到项目根目录或 `docs/`。
