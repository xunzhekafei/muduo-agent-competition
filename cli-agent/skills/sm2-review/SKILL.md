# SM-2 间隔重复复习（Spaced Repetition）

核心思想：**遗忘有曲线，在快要忘记的时候复习效率最高**。
木铎用 SM-2 算法给每张记忆卡排下次复习时间：复习评级越好，间隔越长。

## 触发时机

- 学习者问「今天该复习什么」「帮我安排复习」
- 你制定了当日学习计划，需要加入复习环节
- 学习者刚做完一组记忆卡复习，需要记录结果

## 标准流程

### 1. 看今天有什么 —— `list_due_cards(limit)`

- 返回到期卡片的问答内容。给学习者安排复习时，**先看这张清单再定计划**
- 卡片多时分批：每天 10-20 张为宜，优先到期最久的

### 2. 组织复习 —— 先问后对答案

- 把卡片正面（问题）发给学习者，让他先答，再对答案
- **不要把正反面一起甩出来**——主动回忆才是记忆巩固的关键
- 学习者答错的卡片，可以当场再问一次变体问题确认是否真的记住

### 3. 记录评级 —— `schedule_review(card_id, grade)`

评级标准（按学习者实际表现）：

| grade | 表现 | 排期效果 |
|-------|------|---------|
| `again` | 完全忘了/答错 | 间隔重置，很快再见到 |
| `hard` | 答对但很吃力/犹豫 | 间隔小幅增长 |
| `good` | 答对，比较顺 | 间隔按 SM-2 正常增长 |
| `easy` | 秒答，非常熟 | 间隔大幅增长 |

**诚实评级**——把「其实忘了」标成 good 会让卡片排得太远、真正忘掉。宁可标 again。

### 4. 新卡片从哪来 —— `generate_memory_cards(note_id, max_cards)`

- 学完新笔记后生成卡片，进入间隔重复循环
- 生成后抽查质量：卡片应该是「一个问题一个考点」，太宽泛的下次复习时可以建议学习者重记

## 原则

- 复习计划要具体：明确「今天复习哪 N 张、预计多少分钟」
- 到期卡片为空时不要硬凑——建议学习者学新内容并生成卡片
- 把复习结果和掌握度联系起来：连续 again 的知识点，建议回看原笔记（get_note）或做费曼练习
