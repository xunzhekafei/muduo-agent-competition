# 苏格拉底式提问（Socratic Questioning）

核心思想：**不直接给答案，用问题引导学习者自己发现矛盾、补齐推理**。
适用场景：概念理解浅、结论记住了但推导过程不清、笔记里标了「待理解」的问题。

## 触发时机

- 学习者的提问是「X 是什么？为什么？」这类可以直接查笔记的问题——先查笔记（search_notes/get_note）作答，再用提问引导深入
- 学习者的表述出现「大概是」「反正就是」等含糊词
- 学习者想「深入理解」而不只是「记住结论」

## 工具用法 —— `ask_thinking_question(note_id, goal, question, prompt_type)`

每条引导问题按四类设计，`prompt_type` 对应：

| prompt_type | 作用 | 示例 |
|-------------|------|------|
| `socratic` | 追问推理链条 | 「你是怎么从 A 推出 B 的？中间省略了哪一步？」 |
| `gap_check` | 暴露知识盲区 | 「这个结论的前提条件是什么？去掉它还成立吗？」 |
| `counter_example` | 用反例检验 | 「有没有一个例子，满足你说的条件但结论不成立？」 |
| `revision` | 促使修正表述 | 「把你刚才的说法用一句话重写，去掉所有模糊词。」 |

- `goal`：本次思考想达到的目标（如「弄清虚拟内存存在的原因」）
- 问题发出后**停下来等回答**，不要自问自答
- 根据回答选下一类：答对 → counter_example 检验；答错/含糊 → gap_check 找盲区；逻辑跳跃 → socratic 追推理

## 引导节奏

1. 一轮一个问题，等回答再继续（最多 3-4 轮，别变成审讯）
2. 学习者连续答不上 → 降档：给出 1-2 个选项让他选，或补一点背景再问
3. 有突破时立刻总结：「所以你自己推出了 X」——把发现归功于学习者
4. 结束时把结论沉淀：建议 create_note 记下推导链，或生成记忆卡

## 原则

- 问题要落在学习者「最近发展区」：太易无聊、太难劝退
- 目标是让他自己说出来，而不是你替他说完再问「对不对」
- 与费曼练习的分工：费曼检验「讲不讲得出」，苏格拉底解决「想不想得通」
