## 这是什么

一个面向学习场景的 AI Agent 智能体：它能听懂你的学习需求，自主调用十余种学习工具（查笔记、
知识库检索、生成记忆卡、SM-2 复习排期、费曼讲解评估、苏格拉底式追问……），基于你自己的
笔记和学习数据给出个性化安排，全程的工具调用过程在界面上实时可见。

## 建议体验路径（约 5 分钟）

**1. 个性化复习规划** —— 在对话框发送：

> 帮我安排今天的复习

Agent 会先查询你的学习总览、到期记忆卡和掌握度画像（可展开回复上方的「已执行 N 个工具」
查看每一步的调用与结果），然后给出具体到卡片、带时间估计的复习计划。

**2. 基于自己笔记的问答（知识库语义检索）** —— 发送：

> 用我自己的资料讲讲死锁的四个必要条件

Agent 会从知识库语义检索相关原文片段，结合你的笔记作答，并指出笔记里没讲透的地方。

**3. 费曼讲解评估** —— 发送：

> 我学完了进程与线程，帮我检验一下理解得对不对

用自己的话讲一遍概念，Agent 会针对讲解中的漏洞逐个追问，最后给出评分与改进建议。

**4. 看看工具轨迹** —— 每条回复上方的「已执行 N 个工具」可展开：
每一步调用了什么工具、传了什么参数、返回了什么；点击工具名可直接跳转到对应功能页
（记忆模式 / 费曼模式 / 学习总览……）。

## 提示

- Agent 回复需要 10–30 秒（多步工具调用与模型推理），请稍候
- 左侧导航可浏览完整产品：速记、资源转笔记、思考模式、记忆模式、费曼模式、共享社区
- 如遇模型服务波动导致回复失败，请稍后重试一次
