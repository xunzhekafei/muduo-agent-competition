## 上传的 Word 文件内容

> 文件名：操作系统-进程管理.docx

```
第3章 进程管理

3.1 进程的概念
进程是操作系统中最基本、最重要的概念之一。进程是程序的一次执行过程，是系统进行资源分配和调度的基本单位。

3.2 进程的状态
进程在其生命周期中会在五种状态间转换：
- 创建态（New）：进程正在被创建
- 就绪态（Ready）：进程已准备好运行，等待CPU分配
- 运行态（Running）：进程正在CPU上执行
- 阻塞态（Blocked）：进程等待某个事件（如I/O完成）
- 终止态（Terminated）：进程执行完毕

3.3 进程与线程的区别
- 进程是资源分配的基本单位，线程是CPU调度的基本单位
- 进程拥有独立的地址空间，线程共享进程的地址空间
- 进程间切换开销大，线程间切换开销小
- 进程间通信需要IPC机制，线程间可以直接读写共享内存

3.4 死锁
死锁是指两个或多个进程无限期地等待对方释放资源的状态。
死锁的四个必要条件：
1. 互斥条件：资源只能被一个进程占用
2. 请求与保持条件：进程在持有资源的同时请求新资源
3. 不可剥夺条件：资源不能被强制释放
4. 循环等待条件：存在进程资源的环形等待链

3.5 银行家算法
银行家算法是一种避免死锁的经典算法，由Dijkstra提出。
核心思想：在分配资源前，先判断系统是否会进入不安全状态。
如果发现分配后系统可能死锁，则拒绝本次分配。
```

## 实现方式

在 `QuickNotes.jsx` 中新增一个 demo 模式，用 `useState` 初始化时直接加载固定数据：

```js
// 如果 URL 带 ?demo=1 参数，加载演示数据
const isDemo = new URLSearchParams(window.location.search).get('demo') === '1';

const INITIAL_TIMELINE = isDemo ? DEMO_TIMELINE : [
  { id: 1, type: 'system', content: '速记已就绪...', timestamp: '00:00:00' }
];

const INITIAL_STRUCTURED = isDemo ? DEMO_STRUCTURED_NOTES : [];
```

访问 `http://localhost:3000/quick-notes/timeline?demo=1` 即可演示。
